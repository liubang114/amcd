AL-1S Minecraft Downloader (amcd) — 使用说明 / User Guide

【两种使用方式 / Two ways to run】
1. 双击 amcd.exe 进入交互模式，出现 ">>>  " 后输入命令，exit 退出。
   Double-click amcd.exe for interactive mode; type commands after ">>>  ", exit to quit.
2. 在 CMD / PowerShell 中直接使用：amcd dl -1.20.1
   Use it directly: amcd dl -1.20.1

【命令 / Commands】
dl  [-版本] [-forge|-neoforge|-fabric|-quilt] [-加载器版本] [-路径] [-下载源]
    下载原版或带模组加载器的游戏 / download vanilla or a modded instance
    例 / e.g.  amcd dl -1.20.1 -forge -47.4.28 -E:\mc
    路径含空格时加引号 / quote the path when it contains spaces:
      amcd dl 1.20.3 -forge "-E:\my games\mc"

ls [release|snapshot|old_beta|old_alpha]
    按时间升序列出所有可下载的游戏版本 / list downloadable versions, oldest first
    例 / e.g.  amcd ls release

java ls
    列出可安装的 Java 运行时及安装状态 / list installable Java runtimes
java install <组件名|主版本号>
    安装指定 Java 运行时 / install a specific runtime
    例 / e.g.  amcd java install 17

ins <文件名.zip|文件名.mrpack> [-路径]
    安装 modpacks 目录下的整合包 / install a modpack from the modpacks folder
    支持 Modrinth (.mrpack) 与 CurseForge (.zip) 两种格式
    Supports Modrinth (.mrpack) and CurseForge (.zip)
    例 / e.g.  amcd ins 整合包.zip -E:\mc

【目录 / Layout】
amcd.exe        主程序 / the executable
config.toml     配置文件（TOML，含中英双语注释）/ TOML configuration with bilingual comments
version/        默认安装目录 / default install root
modpacks/       放整合包 zip / drop modpack zips here
logs/           运行日志与安装器日志 / run logs and installer logs

【config 字段 / config fields】
default_path        默认安装路径 / default install path
default_source      默认下载源（BMCLAPI 根地址）/ default mirror root
language            界面语言：zh_cn 或 en_us / UI language
curseforge_api_key  CurseForge API Key；留空时只能使用整合包自带的直链
                    Optional; without it only inline download URLs are used

【目录结构 / Layout】
libraries/ 与 assets/ 放在安装根目录（与 PCL、HMCL 的 .minecraft 结构一致），实例目录只放 <实例名>.json、<实例名>.jar、natives/。
libraries/ and assets/ live at the install root (PCL/HMCL compatible .minecraft layout); the instance folder holds the json, jar and natives.
实例名：原版为版本号，带加载器为 <版本号>-<加载器>，整合包为清单名称。
Instance name: the version id, <version>-<loader>, or the modpack name.

【Java / Java runtimes】
Forge / NeoForge 安装需要 Java；缺少时会询问是否自动安装（来源：Mojang 官方运行时清单，BMCLAPI 加速）。
Forge/NeoForge need Java; if missing, amcd offers to install one from Mojang's runtime index.
可手动安装多个版本 / install specific versions: amcd java ls、amcd java install 8|17|21|<组件名>
运行时装在 runtime/<组件>/ 下 / runtimes live under runtime/<component>/.

【下载行为 / Download behaviour】
- 下载由 BMCLAPI 提供加速；镜像节点不可用时自动回退官方源，并对限流（403/429）退避重试。
  Accelerated by BMCLAPI with automatic fallback to official sources and backoff on rate limits.
- 已存在的文件按 SHA-1 校验后跳过，可反复运行同一命令续装。
  Existing files are verified by SHA-1 and skipped, so re-running resumes safely.
- 按 Ctrl+C 可中断，未完成的文件保留为 .part，下次重试会重新下载。
  Ctrl+C interrupts safely; unfinished files stay as .part and are re-downloaded next run.

【整合包限制 / Modpack limitation】
CurseForge 整合包只记录 projectID/fileID 时，需要填写 curseforge_api_key 才能解析下载地址；
未填写时这些文件会被跳过并提示数量，其余内容（游戏本体、加载器、overrides）仍会正常安装。
CurseForge packs that only carry projectID/fileID need curseforge_api_key; otherwise those files
are skipped with a count, while the game, loader and overrides still install normally.
